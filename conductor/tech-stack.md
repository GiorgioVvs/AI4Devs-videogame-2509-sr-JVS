# Tech Stack

This document outlines the technologies used in the Worminator project.

## Frontend
- **HTML5:** For the game's structure and the canvas element used for rendering.
- **CSS3:** For styling the UI, layout, and providing a clean, modern look.
- **Vanilla JavaScript:** For the core game logic, player input, and real-time rendering on the canvas.

## Backend
- **N/A:** Worminator is a client-side static web application.

## Tooling & Utilities
- **Python:** A helper script (`index-videogames.py`) is used to maintain the project's game index.
