# Product Guidelines

## Visual Identity
Worminator follows a **Minimalist & Modern** visual aesthetic. This includes:
- **Clean Lines:** Using vector-like shapes for the worm and prey.
- **Restricted Color Palette:** Utilizing a few key colors to distinguish between different prey types and the game state.
- **Smooth Animations:** Focus on fluid movement transitions for the worm's "jumping" action and growth.

## Tone and Voice
The game's communication style is **Minimalist & Direct**:
- **Concise Messaging:** All UI elements and game messages use short, functional text.
- **Functional Focus:** Clarity is prioritized over character or lore, ensuring the player always understands their current status and score.

## User Experience (UX)
- **Fluidity:** The core mechanic of "jumping" must feel responsive and intuitive.
- **Visual Feedback:** Clear, distinct visual cues when different prey types are consumed.
